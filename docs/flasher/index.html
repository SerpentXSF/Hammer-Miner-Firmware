Stay Open
This build is for the Hammer BC01 only

Open firmware for the Hammer BC01. Measured on hardware: 1.6–1.7 TH/s at 750 MHz, 24 W, around 54 °C, no hardware errors.

Not for BC04, BC02, BC06 or BC08

The board model is fixed when the firmware is compiled, and the boards do not share a pinout. The BC01 and BC04 have their ASIC UART lines swapped — TX 18/RX 17 against TX 17/RX 18 — so a BC01 image on a BC04 crosses transmit and receive. The miner boots, the web UI works, the chip is even detected, and it never returns a single share. It looks like broken hardware and it is not.

Those models are supported in the source and can be built from it; only the BC01 is published here, because only the BC01 has been run on real hardware.

Check your device before you flash

Retail BC01 units ship with Secure Boot enforced and both spare key slots revoked. On one of those this firmware will not boot and cannot be recovered — eFuses are permanent and USB access does not help. Ask the device first:

esptool.py --port COM3 get_security_info

If secure_boot_en is set, stop. The ESP32-S3 is a socketed LilyGO T-Display-S3, so fitting a fresh module runs this firmware with no exploit and leaves your original untouched — see SECURE-BOOT.md and HARDWARE-SWAP.md.

This browser cannot talk to serial devices. Use Chrome or Edge on a desktop, or flash with esptool instead. Serial access needs a secure context — open this page over HTTPS.

Chrome or Edge on desktop. Connect the miner's ESP32-S3 by USB‑C first.

Nothing here mines to us

The image carries no credentials. Its settings partition is built from the public template, so a freshly flashed miner starts its own WiFi access point and waits for you to enter your network, your pool and your own payout address. Set an API password while you are there — leaving it blank disables authentication, which is how the vendor firmware shipped.

Or do it yourself

Build from source ESP-IDF 5.5.1. Full source, GPL-3.0.
Flash with esptool esptool.py --chip esp32s3 write_flash 0x0 serpentx-bc01-2.0.9-full.bin
Update over the air Upload the -ota.bin through the miner's own update page. Keeps your settings.
